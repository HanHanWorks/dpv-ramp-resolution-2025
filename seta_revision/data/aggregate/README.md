# Public aggregate tables

These CSV files are compact product- or experiment-level summaries selected
for public inspection. They contain no station identifiers, coordinates, raw
hourly observations, or event timestamps. They are derived from privately held
source inputs and do not replace those inputs.

Before creating a release, confirm that the applicable provider or purchase
agreement permits redistribution of derived summaries. If the terms are
unclear, remove the affected table from the commit and release asset.
